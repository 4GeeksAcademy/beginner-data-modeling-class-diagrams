# 09 - Complete Model

Spanish version: [README.es.md](./README.es.md)

## Scenario

Your digital library model should now tell a coherent story: who borrows what, where books live, and who wrote them.

## Instructions

Polish the **same diagram** in [diagram.4geeks.com](https://diagram.4geeks.com/):

1. Include **at least four entities** (you should already have `Book`, `Member`, `LibraryCard`, `Branch`, `Author`, and `Loan`).
2. Label **every relationship** with cardinality (1:1, 1:N, N:M).
3. Keep the layout **readable** — avoid overlapping lines where possible; align related classes.
4. Verify every property still has an explicit **data type**.

## Checklist

- [ ] Four or more classes are present.
- [ ] 1:1, 1:N, and N:M patterns from earlier steps are all represented.
- [ ] Diagram is understandable without oral explanation.
