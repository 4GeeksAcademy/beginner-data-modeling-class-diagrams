# 09 - Modelo completo

Version en ingles: [README.md](./README.md)

## Escenario

Tu modelo de biblioteca digital debe contar una historia coherente: quien pide que, donde estan los libros y quien los escribio.

## Instrucciones

Pulir el **mismo diagrama** en [diagram.4geeks.com](https://diagram.4geeks.com/):

1. Incluye **al menos cuatro entidades** (ya deberias tener `Book`, `Member`, `LibraryCard`, `Branch`, `Author` y `Loan`).
2. Etiqueta **cada relacion** con cardinalidad (1:1, 1:N, N:M).
3. Mantén un diseno **legible** — evita lineas superpuestas cuando puedas; alinea clases relacionadas.
4. Verifica que cada propiedad siga mostrando un **tipo de dato** explicito.

## Lista de verificacion

- [ ] Hay cuatro o mas clases.
- [ ] Estan representados los patrones 1:1, 1:N y N:M de pasos anteriores.
- [ ] El diagrama se entiende sin explicacion oral.
