# 01 - First Entity

Spanish version: [README.es.md](./README.es.md)

## Scenario

A digital library tracks books. Start by modeling a single entity before adding members or loans.

## Instructions

In [diagram.4geeks.com](https://diagram.4geeks.com/), create a class **`Book`** with these **typed properties**:

| Property | Type |
|----------|------|
| `id` | `int` |
| `title` | `string` |
| `isbn` | `string` |

## Checklist

- [ ] One class named `Book` is visible on the canvas.
- [ ] All three properties show their data types.

Continue to **02 - Second Entity** and keep the same diagram file.
