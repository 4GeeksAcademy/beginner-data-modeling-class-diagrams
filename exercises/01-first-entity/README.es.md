# 01 - Primera entidad

Version en ingles: [README.md](./README.md)

## Escenario

Una biblioteca digital registra libros. Empieza modelando una sola entidad antes de agregar socios o prestamos.

## Instrucciones

En [diagram.4geeks.com](https://diagram.4geeks.com/), crea la clase **`Book`** con estas **propiedades tipadas**:

| Propiedad | Tipo |
|-----------|------|
| `id` | `int` |
| `title` | `string` |
| `isbn` | `string` |

## Lista de verificacion

- [ ] Una clase `Book` visible en el lienzo.
- [ ] Las tres propiedades muestran su tipo de dato.
