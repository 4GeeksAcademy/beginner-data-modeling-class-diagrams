# 02 - Segunda entidad

Version en ingles: [README.md](./README.md)

## Escenario

Los socios piden libros prestados. Agrega una segunda entidad junto a `Book`.

## Instrucciones

En el **mismo diagrama**, agrega la clase **`Member`** con:

| Propiedad | Tipo |
|-----------|------|
| `id` | `int` |
| `name` | `string` |
| `email` | `string` |

Aun no conectes `Member` con `Book`.

## Lista de verificacion

- [ ] `Book` del paso 01 sigue presente.
- [ ] `Member` tiene las tres propiedades tipadas.
