# 02 - Second Entity

Spanish version: [README.es.md](./README.es.md)

## Scenario

Members borrow books from the library. Add a second entity alongside `Book`.

## Instructions

On the **same diagram**, add class **`Member`** with:

| Property | Type |
|----------|------|
| `id` | `int` |
| `name` | `string` |
| `email` | `string` |

Do not connect `Member` to `Book` yet.

## Checklist

- [ ] `Book` from step 01 is still present.
- [ ] `Member` has the three typed properties.
